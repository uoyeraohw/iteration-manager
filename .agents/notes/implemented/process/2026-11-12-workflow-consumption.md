# Agent Note: 通用消费闭环与只读耗时汇总

Status: implemented

## Problem

现有就绪检查和attempt记录需要主控主动消费，上一批CLI子进程验证没有覆盖原生代理回收。跨尝试没有只读耗时汇总；Git续跑也没有明确拒绝位于Git仓库内的FS任务，可能越过已声明的恢复模式边界。

## Decision

复用现有事件账和envelope，给主控、主管及审查模板补充最短消费顺序与证据沿用依据，不新增状态或调度平台。新增只读`--execution-report <迭代目录>`：逐卡库存、原始phase、attempt计数、去重会话与命令区间；缺失保持null，冲突和坏卡显式报告。并行区间并集与资源累计量分列，不估算TDD编写或纯开发占比。

resume-checkpoint在读取真实Git检查点前核对卡片模式及显式profile；FS和非法profile拒绝且不写卡。旧Git调用、grant及四预算不变，不实现FS恢复。

可选会话轨迹独立于任务事件账：主控经明确授权创建项目内JSONL，盘点入口显式开启时记录起止与结果，也可引用真实runner收据或导入已有观察；只读报告区分已知累计、并集和未覆盖墙钟。轨迹不改变旧入口、验收或任务卡，也不把未覆盖时间解释成推理或空闲。未完成观察保留未知，原始证据由调用者保留核对。

会话结束后允许追加绑定真实会话ID和时钟基准的独立终态观察，关联旧起点且保留两个来源；不覆盖历史，也不合并冲突或猜测未知边界。轨迹逐卡采集检查时读取到的context阶段及匹配关系，保留旧observed_phases作为检查结果阶段，不从事后可变文件重建历史。

分类报告保留`complete`原有的已记录区间完整性语义，并增加同值的`recorded_intervals_complete`；单独输出`full_activity_coverage=UNKNOWN`，因为现有可选采集无法证明全程覆盖。空分类可以记录完整而覆盖未知，不将零已知耗时解释为没有活动；旧字段、退出码与只读行为不变。

## Alternatives considered

- 另建自动调度器：可强制接管派发，但重复现有主控责任、扩大接口和部署范围；本批只落实消费路径。
- 完整FS恢复：可覆盖非Git中断，但需要新的冻结候选、授权、终态与防重放协议；当前优先正常检查点交接，只堵住跨模式误用。
- 将命令耗时总和称为测试耗时：便于展示，但并行及重复引用会夸大时间，且缺少测试编写记录；保留不同度量和UNKNOWN。
- 将所有分段强制写入attempt：可复用现有事件账，但只读主控会话可能没有任务attempt，且会改变旧任务合同；采用可选会话轨迹。
- 覆盖原会话观察以补终点：格式简单但会丢失原始观察与冲突来源；采用显式终态追加。

## Testing

恢复拒绝四例取得真实断言RED，修正后旧Git恢复及新增边界共34项通过。汇总CLI核心用例先失败后通过，覆盖跨卡去重、并行累计/并集、冲突、坏库存、旧卡、未启动与未知时间及只读。首轮针对性82项通过（47.75秒）、全套253项通过（240.34秒）。

隔离Git Strict-TDD与FS Spike-Discovery样例经原生collaboration默认代理两轮实际读取，主控查询终态后登记attempt/release，下一会话继承检查点；稳定事件重放不重复计数，四预算保持0，另一张授权BLOCKED卡不拖停独立READY卡。样例保持TESTING/UNKNOWN；原runner输出未重跑或改写。原生工具没有提供精确会话起止，故报告保留null。证据在`build/batch3-workflow-20261112/`；这不是已部署助手消费或业务整链验收。

首轮非参与者独审发现报告可跟随项目外任务卡符号链接。数字/非数字名两用例取得真实断言RED后，发现函数增加仅供报告使用的可选read_root，识别期间不读取越界文本；逐卡读取前再次拒绝且保留错误库存。旧调用省略参数不变。受影响129项通过（62.19秒），修正后全套255项通过（209.66秒）；新非参与者对修正包聚焦复核APPROVED。首轮审查未运行独立测试且未给最终批准，完整批次由主代理结合两次审查、最终差异与真实测试作出验收，不把聚焦批准扩称为全范围批准。独审及处理结果见该目录的review记录。

字段澄清的空观察和单条观察用例先因缺少新字段真实失败；实现后针对性45项通过，覆盖未结束、全局错误、跨时钟和只读。对先前真实会话消费验证的隔离轨迹重出报告，去除新增字段后与原报告完整相等；该样例不是正常业务节时证据。收据和报告在`build/timing-coverage-20261113/`。

## Consequences

报告只消费已记录的观察，不能证明原生来源真实性或业务节时比例；真实验证、独立审查和新候选绑定仍按原合同执行。上述实现批次当时不部署副本，不迁移或修改业务项目；后续副本部署需另行授权。
