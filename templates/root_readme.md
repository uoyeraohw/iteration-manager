## 🧭 迭代导航与执行规范
1. **启动迭代**：调用 `/iter next [迭代序号]` 获取新窗口专属整阶段执行 Prompt；
2. **启动单任务**：调用 `/iter task [迭代序号] [任务序号]` 获取指定子任务的高聚焦执行 Prompt；
3. **状态维护与零触碰隔离**：在 Worktree 分支中，由唯一卡片写者按授权维护所属任务卡及迭代 README，实现者返回证据；**绝对禁止修改本总控文件**；
4. **全局聚合**：只有获准合流后，才在根索引写入授权内通过 `/iter sync` 刷新全局大盘；Git提交、推送和清理分别按各自授权，不因验收通过自动执行。
5. **仅生成Prompt**：只交付预览，不写文件、不提交、不创建Worktree；实际执行或创建Worktree前仍必须通过 `--verify-committed`，无Git提交权限时不自动补Commit。
