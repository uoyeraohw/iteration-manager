## 🧭 迭代导航与执行规范
1. **启动迭代**：调用 `/iter next [迭代序号]` 获取新窗口专属整阶段执行 Prompt；
2. **启动单任务**：调用 `/iter task [迭代序号] [任务序号]` 获取指定子任务的高聚焦执行 Prompt；
3. **状态维护与零触碰隔离**：在 Worktree 分支中，每个子任务完成后仅回写所属迭代目录内部卡片（任务卡与迭代 README），**绝对禁止修改本总控文件**；
4. **全局聚合**：各 Worktree 分支合并至主干 (main) 后，通过 `/iter sync` 毫秒级统一扫描并幂等刷新全局大盘。
